# Claude 远程开发服务(终端版)· 使用说明

> 这一版**不用装 Wave、不用 Tailscale**:打开终端 → `ssh cloud` 连上服务器 → 敲 `claude` 开始,和你平时本地用 Claude Code 一样。以下按常见问题说。

## 1. 每天怎么进 Claude?
- **第一步**:打开终端(Mac 用「终端」App;Windows 用「PowerShell」或「终端」)。
- **第二步**:敲 `ssh cloud` 连上服务器。
- **第三步**:连上后敲 `claude` 开始对话——**和你本地用 Claude Code 一样**。
- 断网 / 合盖 / 换 WiFi 后:重新 `ssh cloud` 再敲 `claude`,会**接回刚才的会话**,对话不丢。

## 2. 第一次怎么开通?(一次性)
- 在你电脑上跑一个一键脚本配好「免密连接」,跑完屏幕会出一行「本机公钥」,发过来即可。
- 之后每天只用 `ssh cloud` 这一条,别的不用管。

## 3. 怎么登录 Claude 账号?
- 用发给你的**临时网页链接**在浏览器打开,登录你自己的 Claude 账号即可(只需一次)。

## 4. 怎么开多个对话?
- 和本地一样:`ssh cloud` 连上后默认在工作区 `/opt/workspace`,**`cd` 到不同的项目文件夹、各自敲 `claude`**,每个文件夹就是一个**独立对话**(互不干扰,都能断线接回)。
- 建议同时活跃 10 个以内(服务器内存有限,不用的敲 `/exit` 关掉释放)。

## 5. 怎么切换模型?
- 在 Claude 里输入 `/model` 切换;不确定就直接问 Claude「怎么切模型」。

## 6. 怎么看用量 / 额度?
- 在 Claude 里输入 `/usage` 查看。

## 7. 能不能直接操作我电脑本地的文件?
- 可以。把文件路径告诉 Claude,它能自己取过去处理、也能把结果送回你电脑(通道一键脚本已设成开机自动连,一般不用管)。

## 8. 能不能用 Claude 的桌面客户端?
- 不可以。只能用 **Claude Code**(就是 `ssh cloud` 进的这个)和 Claude 网页版。

## 9. 开了多个对话之间怎么协作?
- 把一个会话里显示的名字告诉另一个,就能让它们互相通讯。

## 10. 能不能帮忙拉起本地的容器 / 项目?
- 可以,直接跟 Claude 说。

## 11. 后续费用?
- 只需要**服务器费用** + **Claude 账号续费**,没有别的。

## 遇到问题
- **`ssh cloud` 连不上 / 超时**:多半是网络,换个网或稍后重试。
- **让你输密码**:免密没配好(少见),重跑一次开通脚本即可。
