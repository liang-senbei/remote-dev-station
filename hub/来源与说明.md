# Hub(agent-hub)—— remote-dev-station 的一部分

多会话协同基础设施。**本目录 `cloud-setup/hub/` 就是唯一源**:`~/.local/bin/hub` 软链到本目录 `hub.sh`,所有 cc 会话跑的就是这份。**改 hub = 改本目录 `hub.sh` + `git commit && push`**,一处搞定,无需再同步、无上游。

## 来源
- 原始上游:第三方开源 `https://github.com/liang-senbei/agent-hub`(MIT,见 `LICENSE`)。
- **上游就是我们自己的仓库**(liang-senbei 是本人账号,有推送权)。2026-06-22 起把 hub 并入本仓便于随部署一起版本管理,旧的 `/root/agent-hub` 克隆已删除,日常改动**以本目录为准**。
- **本仓的改动会回推上游**(2026-08-01 已把定向群发 / HUB_ALL_OK / 去重 / 发送日志 / 加固护栏 / 远程参与者一并推回 `agent-hub`),两边保持同源。改完 hub 记得两边都提交。

## 硬规则
`hub say` / `ask` / `all`(及 raw `tmux send-keys` 到 `cc-*`)**发送前必须人工确认**(`~/.claude/hooks/hub-gate.py` + `settings.json` 的 `permissions.ask` 兜底)。只读 `ls` / `peek` 不拦。

> 部署提醒:这两样在 `claude-config/` 里是现成的,但**要真的装到 `~/.claude/` 才生效** ——
> 2026-08-01 核实时发现服务器上一直没装(hooks 目录都不存在),硬规则形同虚设、一道拦截都没有。
> 装法:`python3 claude-config/enable-hub-gate.py`(幂等、只追加不覆盖、自动备份;详见 `DEPLOY.md`)。
> 装完只对**新起的会话**生效(Claude Code 不热重载 settings.json)。

## 改它
直接编辑本目录 `hub.sh`(= live,软链跑的就是它)→ `git commit && git push`。
