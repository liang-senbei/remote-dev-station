# Hub(agent-hub)—— remote-dev-station 的一部分

多会话协同基础设施。**本目录 `cloud-setup/hub/` 就是唯一源**:`~/.local/bin/hub` 软链到本目录 `hub.sh`,所有 cc 会话跑的就是这份。**改 hub = 改本目录 `hub.sh` + `git commit && push`**,一处搞定,无需再同步、无上游。

## 可选闸门:发送前人工确认(**默认不开**)
`hub say` / `ask` / `all`(及 raw `tmux send-keys` 到 `cc-*`)可以要求**发送前人工确认**(`~/.claude/hooks/hub-gate.py` + `settings.json` 的 `permissions.ask` 兜底)。只读 `ls` / `peek` 不拦。

> ⚠️ **默认不启用,建议保持关闭。** 闸门要求每条跨会话消息都等人点确认 —— 在「会话少、
> 怕 AI 乱发」时是对的,但本机常年并行 20+ 个 agent、彼此高频对接,每条都等人点等于把
> 自动化协作拖死。2026-08-01 实际启用后当天即回退。
>
> 想开:`python3 claude-config/enable-hub-gate.py`;关:`python3 claude-config/disable-hub-gate.py`。
> 两个脚本都是幂等的、只增删自己那两项(permissions.ask 三条 + PreToolUse 一个钩子),
> 不碰 env / 模型 / cc-state 钩子,改前自动备份。
> 只对**新起的会话**生效 —— Claude Code 不热重载 settings.json(实测:文件被替换后它只用
> `O_PATH` 重建 inotify 监听,从不重读内容)。
>
> 不开闸门时,靠纪律约束:别拿 `hub all` 广播私事、发之前先 `hub peek` 看对方在不在输入框。
