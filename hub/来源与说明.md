# Hub(agent-hub)—— 折入本 infra 仓的备份副本

多会话协同基础设施。本目录是**备份副本**(随 `remote-dev-station` 版本管理);**实际运行**的在服务器 `/root/agent-hub/`(软链到 `~/.local/bin/hub`)。

## 来源
- 上游:第三方开源项目 **`https://github.com/liang-senbei/agent-hub`**(许可见同目录 `LICENSE`)。我们采用它做"多 cc 会话查看 + 互发消息"的基础设施。
- `/root/agent-hub` 是它的克隆,**track 上游、可 `git pull` 拉更新**;但我们**没有上游推送权**(`xiaoxihexiaoyu` 对 `liang-senbei/agent-hub` 是 403),所以本地改动推不回上游 → 折进本 infra 仓保存。

## 我们在上游之上的本地改动(上游没有)
1. **`hub iam` / `hub dash` / `hub overview`**:每个会话自报一句话"在做什么"+ 声明有没有看板 → 汇总到 `/opt/workspace/会话总览.md`,各会话/中控一开工即知彼此。详见 `/opt/workspace/references/会话协同.md`(本目录 `会话协同.md` 同)。
2. **跨会话可靠投递 + 留言箱**(另一会话所加):agent-teams 名册让空闲态也可投;投不出存 `~/.hub-inbox` spool,后台看守 `hub _watch` 自动补投;新增 `hub flush`/`hub inbox`。

## 硬规则
`hub say` / `hub ask` / `hub all`(及 raw `tmux send-keys` 到 `cc-*`)**发送前必须人工确认**(`~/.claude/hooks/hub-gate.py` + `settings.json` 的 `permissions.ask` 兜底)。只读 `hub ls`/`hub peek` 不拦。

## 同步
- 服务器改了 → `cp /root/agent-hub/hub.sh /root/cloud-setup/hub/hub.sh` 再提交。
- 从本仓恢复 → 反向 `cp`。
- 拉上游更新 → 在 `/root/agent-hub` 里 `git pull`(注意会和本地改动可能冲突)。
