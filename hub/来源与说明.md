# Hub(agent-hub)—— remote-dev-station 的一部分

多会话协同基础设施。**本目录 `cloud-setup/hub/` 就是唯一源**:`~/.local/bin/hub` 软链到本目录 `hub.sh`,所有 cc 会话跑的就是这份。**改 hub = 改本目录 `hub.sh` + `git commit && push`**,一处搞定,无需再同步、无上游。

## 来源
- 原始上游:第三方开源 `https://github.com/liang-senbei/agent-hub`(MIT,见 `LICENSE`)。
- 上游已不再更新、我们也无推送权 → **2026-06-22 彻底并入本仓**:旧的 `/root/agent-hub` 克隆(track liang-senbei 的那个)**已删除**,不再有"克隆 + git pull 上游"的关系。Hub 现在完全归我们、在 `remote-dev-station` 里版本管理。

## 我们在上游之上的改动
1. **`hub iam` / `dash` / `overview`**:会话自报一句话"在做什么" + 看板声明 → `/opt/workspace/会话总览.md`(详见同目录 `会话协同.md`)。
2. **跨会话可靠投递 + 留言箱**:agent-teams 名册(空闲态也可投)、投不出存 `~/.hub-inbox` spool、后台看守 `hub _watch` 自动补投、新增 `hub flush` / `hub inbox`。

## 硬规则
`hub say` / `ask` / `all`(及 raw `tmux send-keys` 到 `cc-*`)**发送前必须人工确认**(`~/.claude/hooks/hub-gate.py` + `settings.json` 的 `permissions.ask` 兜底)。只读 `ls` / `peek` 不拦。

## 改它
直接编辑本目录 `hub.sh`(= live,软链跑的就是它)→ `git commit && git push`。
