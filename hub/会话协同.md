# 会话协同(hub + 会话总览 + 看板声明)

多个 cc 会话并行时,**互相知道在干嘛 + 知道谁有看板**的协同层。规则在 `/opt/workspace/CLAUDE.md`,本文是细节。

## 1. hub —— 谁在、谁干嘛(基于 tmux,零注册)
`hub`(`/root/cloud-setup/hub/hub.sh`,软链到 `~/.local/bin/hub`)管理**所有 `cc-` 开头的 tmux 会话**。会话在跑就自动在 hub 里,**不用登记、零陈旧**。

| 命令 | 作用 | 读/写 |
|---|---|---|
| `hub ls` | 列所有会话:名/路径/git **+「在做」+「看板」** | 只读 |
| `hub peek <cc> [n]` | 看某会话最近 n 行屏幕 | 只读 |
| `hub iam "一句话"` | **设自己这条会话的「在做什么」** | 写自己 |
| `hub dash <url>\|none [auto\|manual]` | **声明自己有没有看板 + 更新方式** | 写自己 |
| `hub overview` | 重新生成 `/opt/workspace/会话总览.md` | 写总览 |
| `hub say/ask/all` | 给别的会话发消息(**发送前必须人工确认**,见硬规则) | 写别人 |

**agent 间消息格式**(`hub say/ask/all` 由 `_wrap` 自动套,单行——tmux 多行会提前提交):
`[HUB·机器对接] cc:来源(@路径) → cc:目标 ｜类型: 知会/需回复 ｜正文: … ｜回执: … ｜规矩: …`
- **规矩(硬)**:agent↔agent 是**机器对接**,只给结论/数据/字段/决策;**禁开场白·问候·致谢·客套·复述原话·给人看排版**,能一句别两句。
- `say`=**知会**(默认无需回复,少发无意义"收到"),`ask`=**需回复**(必回 `hub say <来源> "<结论/数据>"`)。

## 2. 一句话自报(`hub iam`)
- 每个会话**开工 / 换大方向时**自报一句:`hub iam "项目X:在做某某功能的某某部分"`。
- 存到 `~/.cloud-summaries/<会话名>.txt`(各写各的、无并发冲突)。
- `hub iam` 会顺手刷新总览;`hub iam`(无参)= 看自己当前那句。
- **为什么需要**:`hub ls` 默认只给名/路径,几个同前缀的会话(如 `proj-*`)可能同在一个目录,光名字分不清谁是谁;这句话补上"在干嘛"。

## 3. 会话总览(`/opt/workspace/会话总览.md`)
- 由 `hub overview` **自动生成**(iam/dash 时自动触发),表格:`会话 | 在做什么 | 看板`。**别手编**(会被覆盖)。
- 临时会话 `cc-tmp-*` 不进总览。
- **它是全局协同的关键**:每个 cc 会话开工都会加载 `/opt/workspace/CLAUDE.md`,顺着它就能看到这张总览 → 一开工就知道别的会话在干嘛。

## 4. 看板声明(`hub dash`)+ 三种看板别混
- `hub dash <url> auto` / `hub dash <url> manual` / `hub dash none`,存 `~/.cloud-summaries/<会话名>.dash`,进总览的「看板」列。
- **`auto`** = 看板自动刷新(数据后端自己更),你不用管;**`manual`** = 你得自己更新看板内容。会话据此知道"我要不要管我的看板"。
- 本服务器现有**三类看板,别混**:
  1. **项目看板门户**(`:8088/`,`cloud-dashboards.service` 服务 `/root/inbox/dashboards/`)——给用户点的、各项目自己的看板索引;在 `/root/inbox/dashboards/registry.json` 的 `projects[]` 里注册(有看板的会话往这加自己条目)。
  2. **会话状态看板**(`:8722`,`cloudstatus.service`)——显示各 cc 会话"运行中/待输入/完成";Mac 上 Hammerspoon 浮窗加载它。数据靠 `cc-state` 钩子,**auto**(自动)。
  3. **会话总览**(本文的 `会话总览.md`)——纯文字、给 agent 互相看的(不是网页)。
- 有网页看板的会话:既 `hub dash <url>` 声明(进总览),也按需在 `registry.json` 注册(进 :8088 门户)。

## 5. 存储位置一览
- 一句话:`~/.cloud-summaries/<会话名>.txt`
- 看板声明:`~/.cloud-summaries/<会话名>.dash`
- 总览:`/opt/workspace/会话总览.md`(自动生成)
- 项目看板注册:`/root/inbox/dashboards/registry.json`

## 6. 发消息的硬规则(重要)
`hub say/ask/all`(以及 raw `tmux send-keys` 到 `cc-*`)**发送前必须先问用户**(发给谁、发什么、几条),用户拍板才发。只读的 `hub ls`/`hub peek` 不受限。有系统级钩子兜底(`hub-gate.py`)。
